# Audio Hero Companion

Standalone companion app for [Audio Hero](https://bommerts.com/audiohero/). Turn a
spare Windows PC into a streaming companion for Audio Hero, without installing the
full app.

## Download

Get the latest installer from the
[Releases page](https://github.com/bommerts/Audio-Hero-Companion/releases/latest).
The file name includes the version, for example `AudioHeroCompanionSetup-2.0.1.exe`.

## Requirements

- Windows 10 or 11 (64-bit)
- Microsoft Edge WebView2 Runtime (already present on most Windows 11 PCs; the
  installer offers to add it if it is missing)
- On the same local network as your main Audio Hero PC

## What it does

- Streams web music (YouTube Music, Apple Music, etc.) and local/PC audio to your
  HEOS-compatible speakers
- Installs per-user (no admin rights for the app itself), runs in the system tray,
  and keeps itself up to date automatically from this Releases page
